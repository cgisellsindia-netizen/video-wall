What this mini browser can do

It provides a website address bar, touch navigation for embeddable pages, and basic Back, Forward, Home, and Refresh controls. This browser is an embedded webpage, so sites such as Facebook that block embedding need Safari or a dedicated iOS app with a native WebView. Velvet does not read, record, or automate your activity inside external websites.

Velvet AI is an independent companion and is not affiliated with Meta or Facebook. Facebook credentials are entered only on Facebook, not on Velvet. Messages are not automatically sent.
